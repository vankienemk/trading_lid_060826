## Known Issues / Notes

- **W2 (low)**: RandomForest `n_jobs=-1` (parallel) introduces ~1e-16 floating-point non-determinism across runs due to thread scheduling. For bit-exact reproducibility, set `n_jobs=1` and fix `random_state`. This is documented for report transparency; the variance is negligible for practical purposes.
